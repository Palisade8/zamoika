📚 API ZаМойка для внешних систем

🔑 Авторизация

Для всех запросов требуется передавать API ключ в заголовке:

X-API-Key: ваш-секретный-ключ

📡 Эндпоинты

GET /api/external/services

Получить список всех услуг

Ответ:

{
    "success": true,
    "services": [
        {
            "id": 27,
            "name": "Мойка + 0,4 л. шампуня 15 мин.",
            "duration": 15,
            "price": 250
        }
    ]
}
GET /api/external/free-slots?date=2026-05-27&duration=30

Получить свободные слоты на дату

Параметры:

  • date - дата в формате YYYY-MM-DD
  • duration - длительность услуги в минутах

Ответ:

{
    "success": true,
    "slots": ["09:00", "09:15", "09:30"]
}
GET /api/external/schedule?start=2026-05-27&end=2026-05-28

Получить расписание на период

Параметры:

  • start - начальная дата (YYYY-MM-DD)
  • end - конечная дата (YYYY-MM-DD)
POST /api/external/create-booking

Создать новую запись

Тело запроса:

{
    "client_name": "Иванов Иван",
    "client_phone": "89001234567",
    "date": "2026-05-27",
    "time": "10:00",
    "duration": 30,
    "services": [27, 28],
    "note": "Комментарий",
    "discount": 0
}

Параметры:

  • client_name - имя клиента (обязательно)
  • client_phone - телефон (обязательно, 11 цифр)
  • date - дата записи (обязательно)
  • time - время записи (обязательно, HH:MM)
  • duration - длительность в минутах (опционально, по умолчанию 60)
  • services - массив ID услуг (обязательно)
  • note - примечание (опционально)
  • discount - скидка в % (опционально, 0-100)

Ответ:

{
    "success": true,
    "invno": 17503
}

📝 Примеры запросов

JavaScript (fetch):

// Получить услуги
fetch('https://ваш-домен.ru/api/external/services', {
    headers: {
        'X-API-Key': 'ваш-ключ'
    }
})
.then(res => res.json())
.then(data => console.log(data));

// Создать запись
fetch('https://ваш-домен.ru/api/external/create-booking', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-API-Key': 'ваш-ключ'
    },
    body: JSON.stringify({
        client_name: 'Петров Петр',
        client_phone: '89009998877',
        date: '2026-05-28',
        time: '14:00',
        duration: 30,
        services: [27],
        note: 'Позвонить за час',
        discount: 10
    })
})
.then(res => res.json())
.then(data => console.log(data));

Python (requests):

import requests

API_URL = "https://ваш-домен.ru/api/external"
HEADERS = {"X-API-Key": "ваш-ключ"}

# Получить услуги
response = requests.get(f"{API_URL}/services", headers=HEADERS)
services = response.json()

# Получить свободные слоты
response = requests.get(
    f"{API_URL}/free-slots",
    params={"date": "2026-05-28", "duration": 30},
    headers=HEADERS
)
slots = response.json()

# Создать запись
booking_data = {
    "client_name": "Сидоров Сидор",
    "client_phone": "89001112233",
    "date": "2026-05-28",
    "time": "15:00",
    "duration": 40,
    "services": [29, 26],
    "note": "С собой будет собака",
    "discount": 0
}
response = requests.post(
    f"{API_URL}/create-booking",
    json=booking_data,
    headers=HEADERS
)
result = response.json()
